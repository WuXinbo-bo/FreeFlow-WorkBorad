- 应用更新过滤插件、草稿及预发布；插件 Release 明确不占用 Latest。发布后确认主程序 Latest 仍为 `v2.0.2`。

## 验收边界

- 未在 Windows 真机执行原生窗口、安装器与真实 CLI 回归，不声称 Windows 原生验收完成。
- CLI 流式协议与进程生命周期使用本地测试 CLI；未把它描述为真实云端模型对话。
- 当前公开应用仍为旧 Windows v2.0.2，可能不具备本次源码的插件宿主；新在线目录供本次及后续兼容宿主使用。Mac 应用仍是本地测试版，本轮未发布 Mac 应用安装包，也未完成 Apple 公证。
- `plugins` 是官方分发协议，不是任意第三方代码市场。增加新插件需要先在主程序注册接口、权限与生命周期。
- 原始开发工作树的既有未提交内容未并入本轮应用分支。
