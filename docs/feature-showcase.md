# 特色导览

入口：欢迎页或「使用说明 → 观看特色导览」。七个章节串起同一份示例资料：带格式导入、继续编辑、数学公式、组织思路、图片与文件、AI 镜像、导出 Word。

## 演示内容与边界

- 文本通过真实粘贴事件进入现有导入器，保留标题、列表、强调和链接；后续进入真实编辑器修改。
- `$$` 公式经过现有解析器导入，再编辑 LaTeX 源码并提交。
- 思维导图使用现有根节点、子节点、折叠和展开操作。
- 图片和内存中生成的 DOCX 通过真实文件拖放进入引擎，文件卡使用现有 Word 预览组件。
- **AI 章节只介绍 AI 镜像**。选择目标、嵌入和复制流程使用明确标注的离线示例网页；实际选中网页内容，再经真实粘贴导入器放入画布。不调用 AI 助手、模型或用户的登录会话，也不把示例内容描述为现场模型回答。「体验真实 AI 镜像」退出导览、展开右侧工作区并进入现有镜像教程，真实目标由用户选择。
- Word 使用现有 AST、附件准备和桌面编译接口生成真实 DOCX；调整阅读顺序会重新生成预览。只有点击「导出为 Word」才调用系统保存对话框；取消可以重试。

## 隔离与性能

导览按需加载，关闭时卸载。复用真实 Canvas2D 引擎源码和现有预览组件；新增 UI bundle 不在日常启动路径加载。

示例位于独立 iframe，使用内存 localStorage，关闭画布持久化和工作区初始化。示例文件只在内存 Map 中读取。原画布、视口、未保存状态、撤销历史和系统剪贴板不作为演示操作目标；原工作区的自动保存仍按用户已有设置运行。练习仅本次保留，重播重置示例，关闭后丢弃；需要带走成果时显式保存 Word。

背景工作区临时 inert，退出恢复原有 inert 状态与焦点。已有原生 AI 镜像在导览覆盖期间暂时隐藏，退出后恢复原有显示。暂停以事件等待，不持续轮询；窗口隐藏时暂停。系统「减少动态效果」开启时不自动播放，改为逐步前进，并响应设置的实时变化。

## 状态与恢复链

1. 打开：隔离背景、加载独立画布 → 准备本章 → 播放；减少动态效果时进入暂停。
2. 暂停：保留进度和场景；继续后恢复。失焦可能正常提交编辑器，后续修改步骤会重新进入对应编辑器。
3. 切章／重播：先取消并等待旧步骤结束，再恢复前章检查点；缺失检查点时依次重建。异步导入、Word 回包不能跨章恢复旧界面。
4. 练习：取消演示，等待当前操作结束，再放开画布交互；重播退出练习并恢复示例。
5. 失败：显示错误与重试入口；退出按钮始终独立于引擎存在。
6. 退出：同步停止引擎、观察器及监听器，取消播放、释放对象 URL、移除 iframe，再恢复背景交互和焦点。支持加载中退出、连续开关、快速切章后退出。

## 验证

- `npm run test:feature-showcase`：播放取消与串行化、练习切换、减少动态效果、错误恢复、原生镜像隐藏／恢复调用链。
- `npm run test:feature-showcase-browser`：需要本地服务，可用 `AIR_CANVAS_TEST_URL` 指定；真实引擎、镜像网页选中和粘贴、练习／重播、680/900/1280 宽度布局、动态切换减少动画设置与卸载。
- `npm run test:feature-showcase-desktop`：在隔离的临时配置与画布目录启动真实 Electron，覆盖七章、真实 DOCX 预览／重排／取消保存／再次保存、原画布恢复和重复开关。
- 相关回归：教程浏览器、编辑完整性、Word 选择导出、交付核心、命令集成、共享工作区恢复、生成物一致性。

Word 预览重排时使用新的 iframe 实例，避免 `document.open()` 移除旧窗口消息监听器后，缓存的 JSZip 调度器失效并永久停在「正在渲染」。桌面与浏览器测试都实际验证重排后的文档页面。

本轮实测环境为 macOS；Windows 分支执行共享与构建检查，Windows 原生窗口嵌入仍须在 Windows 设备验证。离线镜像导览不等同于登录第三方网站或原生嵌入的网络实测。
