# 工作区、目录与文件界面调整（2026-10-12）

本轮包含上一轮已授权但尚未提交的文件界面简化，以及本轮工作区导航调整。改动属于跨平台通用逻辑，使用同一源码提交同步到 mac、main、win；平台专用窗口、剪贴板与打包实现保留。两个已跟踪的前端包在各分支根据源码单独构建。

## 状态与恢复规则

- 工作区同步区：首次状态未知时隐藏；授权成功且仓库 owner/repo 有效时显示。关闭自动同步不等于解绑仓库。断网或读取失败时保留最后一次有效绑定及重试入口；断开、解绑或换仓库清除旧检查结果、错误、提示和展开态。旧仓库的迟到检查结果不得写入新仓库。普通待检查使用中性色，冲突和失败使用警示色。本机保存失败单独显示。
- 工作区与画布目录：共用一层磨砂背板，上下独立区域，分别滚动及收起。标题、按钮、缩进和空态对齐。目录序号保留在显示选项里；新增、搜索、收起直接可见。搜索关闭时清空筛选，收起时结束拖拽及元素预览。恢复侧栏不展开小地图，也不修改画布内容。
- 画布信息：整体位于左上三个控制键右侧，同顶部工具栏一行；按控制键实际宽度留空。常态显示名称和本机保存状态；详情保留自动保存信息、重命名及文件位置。空间不足时收起，点击可打开详情浮层；Esc、点击外部、画布切换和自动收起状态变化后关闭并恢复。浮层展开时位于侧栏上方，可点击；教程出现时恢复原工具栏层级，避免遮挡关闭按钮。小窗口工具栏横向滚动仍能访问全部工具。
- 删除右上重复的工作区入口，保留添加文件、侧边恢复入口和 Cmd/Ctrl+P 快速切换。
- 文件转换：统一“转换为 / 格式 / 添加到画布”，基本选项与高级选项分开；关闭、Esc、卸载立即停止状态轮询，取消后台任务，迟到结果不更新已关闭窗口；目录选择可取消，结果文件保持可访问。
- 图片管理：无默认选择，按名称、使用情况和缺失状态筛选。关闭后释放缩略图 URL 和监听，迟到任务不能覆盖新会话。缩略图仅为可见项目生成，最多两路解码、32 个排队、160×120 输出、16 MB 输入及 4000 万像素限制；权限沿用文件访问授权，不允许任意路径读取。独立工具栏样式避免与画布图片工具条冲突。
- 文件预览：阅读控制独立一行，搜索、摘取、转换和源文件操作分组。Esc 优先关闭操作区或裁取模式，再退出阅读。Word 导出统计和历史保留规则可展开查看，风险信息保留。
- 设置：本机保存称为“设置已保存”；GitHub 主操作突出发现和拉取，其他操作仍可展开使用，授权方式不改变。

- 共享测试套件覆盖后端安全、GitHub 同步/冲突、画布核心、复制粘贴、文档预览、后台恢复、工作区布局、设置与 AI。
- 原生 macOS Electron：工作区真实文件保存/切换/删除/回收站/历史恢复；绑定、断网、解绑、换仓库、迟到检查使用隔离 IPC fixtures；连续收起展开、搜索退出、窄栏和顶部信息详情恢复。
- 原生 macOS Electron：图片缩略图、屏外加载预算、刷新/搜索/缺失筛选/插入/撤销、焦点约束、连续重开和窄窗口；使用隔离临时目录，不读取用户令牌。
- 原生 macOS Electron：PDF 阅读、搜索、摘取、裁取、撤销，真实文件转换、保存与添加到画布；LibreOffice 真实转换。转换采样帧间隔 P95 约 8.6 ms，最终面板尺寸调整 P95 约 8.5–9.4 ms，仅代表本机该测试场景。
