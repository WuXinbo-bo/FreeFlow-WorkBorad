# 画布工作区侧栏与恢复验证（2026-10-10）

本轮属于跨平台通用改动，使用同一提交同步到 mac、win、main，保留各分支原生窗口与打包差异。开始前为三个分支建立 `checkpoint/workspace-sidebar-*-20261010` 回退标签。原项目目录的既有修改保持原样；本轮不推送远程。

## 管理入口

- 桌面画布默认显示工作区侧栏，工具栏文件夹按钮直接展开。三个点只保留画布选项与帮助。
- 当前文件夹与最近打开分开显示，搜索、按名称或修改时间排序、单击切换。最近记录最多 12 个，属于本机偏好。
- 新建、保存、另存为、重命名、独立副本、显示位置、删除均有直接入口。副本与另存到新路径的文件获得独立同步 ID；正常加载与保存保留原 ID。
- 文件列表与当前画布内部目录分层。侧栏收起、宽度、小地图与目录偏好不写入同步内容。
- 侧栏打开时只监听一个文件夹，文件变化合并后刷新；关闭、换目录、关窗口时释放监听。不增加后台轮询或多个画布引擎。
- GitHub 状态、检查、拉取、上传在侧栏底部；授权、仓库绑定、冲突处理仍在独立系统设置。
- 无桌面文件桥的网页环境保留原画布目录，不显示不可用的工作区文件入口。

## 状态与恢复

| 操作 | 进入条件 | 退出与恢复 |
| --- | --- | --- |
| 浏览文件夹 | 选择且成功读取目录 | 仅更新工作区；当前路径、内容、图片位置、未保存状态不变 |
| 切换画布 | 单击文件；存在编辑时先确认 | 保存成功再切换；放弃不写盘；取消或读写失败保留当前画布 |
| 新建画布 | 工作区存在且未保存保护完成 | 先写入空画布再加载；写失败不替换原内容 |
| 重命名 | 名称有效且目标不存在 | 活动画布等待写入结束、暂停自动保存、更新路径后恢复；重名不覆盖 |
| 删除 | 非活动画布且二次确认 | 取消保留文件；成功更新文件列表与最近记录；不自动删除远端 |
| 同步 | 等待正在进行的读写并保存当前编辑 | 暂停自动保存；磁盘变化后重载干净画布；失败也检查已完成的局部替换；最后恢复计时器 |
| 同步中再次编辑 | 磁盘更新但内存又有修改或编辑器仍打开 | 保留内存并禁止覆盖新磁盘文件；可另存到新路径或放弃后重载；取消继续保留 |
| 保存期间继续编辑 | 写入尚未完成 | 只清除已写入版本的脏状态；新修改保持未保存，后续保存可以恢复 |
| 侧栏遮挡小地图 | 展开或调整宽度造成重叠 | 暂停绘制但不改变展开偏好；空间恢复后失效旧快照并补绘 |

菜单与确认框进入全局弹层，标记原生窗口点击区域；键盘操作不会落到画布删除等命令。确认框限制 Tab 焦点并在退出时恢复，菜单支持方向键、Home、End、Escape。

## 验证记录

- `check-board-workspace-recovery.js`：真实临时文件，浏览与取消、保存拒绝、新建写失败、成功加载、目录事件合并、监听关闭与重复恢复。
- `check-board-workspace-desktop.js`：本机真实 Electron，独立用户目录。覆盖单击切换、保存/放弃/取消、损坏文件、新建、重名保护、删除确认、最近列表、复制后的同步 ID、文件外部更新、浏览后保存原路径、菜单焦点、重复收起/展开、重载偏好与窄面板。
- 同一桌面测试通过隔离 IPC 模拟拉取，验证活动画布自动重载、干净自动保存不重写、编辑中拉取不覆盖内存、取消与放弃恢复、同步失败后继续保存、延迟写入期间再次编辑不丢脏状态。不会使用真实令牌或写用户仓库。
- `check-github-sync-multidevice.js`：隔离 GitHub 服务 fixture，双设备拉取、旧基线拒绝、附件哈希和中断下载恢复。
- `check-github-sync-safety.js`：无效本地文件保护与远端附件清单限制。
- `run-test-suite.js`：共享安全、画布内容、历史、粘贴、性能恢复、触控板、布局、设置与 AI 会话完整回归。
- `check-desktop-canvas-smoke.js`：本机原生窗口、全屏退出与恢复、画布、捏合与相邻布局恢复。
- 宽与窄面板实际截图检查文字、按钮、弹层及相邻 AI 面板；生成包一致性与 `git diff --check`。

本机是 macOS，Windows 原生窗口、物理触控板和安装器运行仍需在 Windows 机器补验。本轮同步测试为隔离自动化与真实本机文件测试，没有向 GitHub 远程推送。
