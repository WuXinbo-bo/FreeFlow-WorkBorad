# 文件工作台改造与验证

本轮为通用改造，同步 mac、main、win；不推送远程。改造前已建立三个 `codex/safety-*-before-file-workstation-20261011` 回退引用。原始开发目录中的未提交工作不动。

## 分批目标

1. 文件阅读：PDF、DOCX、文本、表格；放大阅读、搜索/摘取、刷新/重新关联、恢复阅读位置。验证旧预览、相机变动、反复打开关闭、删除/撤销。
2. 常用转换：PDF 指定页转图片、图片合并 PDF、图片转格式/缩放、文本转 DOCX/PDF、CSV/XLSX。验证真实文件、输出可读、顺序、取消、异常、同名不覆盖。
3. 内容回流与 Office：文字/页面摘取带来源；本地 Office 转换引擎检测，DOCX 转 PDF 能力明确。验证插入撤销、路径权限、降级提示。
4. 全量回归、桌面实测、性能恢复与代码复审；共享源码提交并同步，生成包分别构建。

## 状态与恢复链

- 阅读：关闭 → 读取 → 解析 → 就绪；失败可重试/重新关联。关闭、删除、切换画布使会话失效；迟到结果不能恢复已关闭窗口。阅读模式只改变预览容器，不改变画布视口；Esc 返回附着视图，关闭后恢复焦点与备忘录。阅读位置按卡片保存，不保存解析器/DOM/二进制。
- 刷新：就绪 → 新代次读取 → 就绪/失败；旧代次结果不可提交。重新关联先选择并检查真实文件，卡片 ID、位置、备忘录、连接保留，改动可撤销。
- 转换：配置 → 选择输出目录 → 运行 → 成功/失败/取消。独立 worker 按需启动，单任务串行；临时文件不暴露为成功产物，同名输出不覆盖。取消/关闭/窗口销毁停止任务并清理临时目录；失败不自动插入卡片。
- 摘取：就绪 → 插入 → 撤销/重做。保留源卡片 ID、文件名、页码和时间，不复制整份文件进画布状态；源文件和源卡片不被修改。

## 性能边界

预览二进制读取前限制为 32 MB；Office 解压预算 32 MB，图片解码上限 1600 万像素；PDF 只渲染附近页面并释放远页；搜索按页异步执行，可取消。转换不在画布主线程运行；限制输入总量、图片像素、PDF 页数及输出大小。表格预览截断行列并提示，保留原文件；CSV 转换明确丢失格式，默认防止电子表格公式注入。Office 引擎缺失不得显示成功。

## 验证记录

- `scripts/check-file-workstation.js`：使用真实 PDF/图片/文本/工作簿，验证选页、图片合并顺序与颜色、尺寸、输出文件可读、CSV 公式防护/负数、同名不覆盖、权限、并发、运行前及运行中取消、窗口销毁、超限拒绝、解压预算、缺少 Office 引擎提示。
- `scripts/check-file-workstation-desktop.js`：隔离 Electron 配置及文件目录，不影响正在使用的应用。验证 PDF 文字层/搜索/页码、文字/整页/区域摘取、撤销重做、保存与批量回流、阅读位置、快速进入退出、重新关联身份/位置/备注、同 stat 强制刷新、DOCX 横向纸张与 iframe 内 Esc、表格消毒、中英文 PDF 可选择文字。实际使用本机 LibreOffice 将横向 DOCX 转为 PDF，并重新解析验证纸张方向。
- 12 页 PDF 在独立 worker 转换期间采集 40 个桌面动画帧：P95 9.3 ms，最大 9.3 ms（另一轮最大 10.2 ms）。这是本机样本，不代表所有机器/所有大文件。
- 完整共享测试套件通过；最终补丁继续通过文档浏览器回归、文件任务/预览缓存测试和原生桌面实测。macOS 路径/前端与桌面打包静态检查通过。
- Windows 分支在此 Mac 上验证共享代码、权限与 Windows 路径/打包静态检查；未进行 Windows 原生运行或安装包实测。新 Office 转换入口要求 LibreOffice；原有 Windows Word 导出线路保留。

## 使用方式与限制

- 文件卡右键“预览”打开附着阅读；右上角 ↗ 放大，Esc 返回；⋯ 打开搜索、摘取、刷新、重新关联及转换。
- PDF 选中文字可摘取；未选择时摘取当前页文本。扫描件不会伪装为可搜索文字，可用整页图片/区域图片；OCR 与 PDF → 可编辑 Word 本轮未实现。
- 文件卡/本地图片右键“转换文件格式 / 合并 PDF”：选择类型、页码/格式/尺寸/顺序，再选择输出目录。成功后可打开所在目录或一次插入全部结果到画布；插入支持整批撤销，磁盘转换文件保留。
- 预览最多三个会话，96 MB 合计缓存预算；PDF 附近页面串行渲染、远页释放，单页预览栅格上限 200 万像素。读取和转换均按需，关闭/取消停止任务，CPU 不响应时 3 秒后强制清理。
- 转换单文件 64 MB、总输入 128 MB、总输出 256 MB；最多 24 张输入图片或 50 页 PDF。文本转换 2 MB、文字 PDF 50 页；表格转换 10 万行/100 万单元格。预览文本限 20 万字，表格限每张 500 行 × 40 列，最多 12 张表，不改变原文件。
- CSV 是值导出，样式/公式/图片不保留，默认第一张表，也可指定名称；文字 Markdown → Word 支持标题与正文，PDF 保留原始可读文本，不请求外部图片。没有宣称完整 Markdown 排版或完整 Office 编辑器。
- LibreOffice 在 macOS、Windows、Linux 分别探测本地安装路径及 PATH；引擎缺失提供明确提示。字体差异可能影响精确版式，支持系统应用打开原件。
- 阅读缩放和位置按本机源路径保存（最多 64 条）；解析器、DOM、文件二进制和转换进度不会写入画布。来源信息保存在摘取/转换卡片，跨设备原文件路径仍可能需要重新关联。
