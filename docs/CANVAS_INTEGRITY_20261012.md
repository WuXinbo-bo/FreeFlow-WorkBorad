# 画布编辑与恢复完整性修复

基线：mac `5af03c2`、main `eb5fc24`、win `4905867`。对应本地 `backup/canvas-integrity-*-20261012` 分支可回退。旧实验工作树不纳入本次修改。

## 执行与验证批次

1. 编辑草稿、保存、撤销与目录/画布元数据恢复。
2. 富文本语义、批量格式事务、稳定编辑尺寸、显示与导出一致性；代码输入与表格公式/链接/导出。
3. 图片变换几何、裁剪异步恢复、思维导图锁定。
4. 转换结果、图片回插、文件摘取与搜索。
5. 异步导出取消/归属、视口动画、导出尺寸与缓存预算。
6. 共享与桌面回归、构建、跨分支同步、最终审查和提交。

## 会话与恢复约束

- 输入进入草稿；保存读取当前草稿且不关闭编辑器；完成编辑生成一次画布历史。保存成功后恢复基线推进到已保存内容。
- 富文本 Esc 恢复最近保存或开始编辑时的基线；切换工具、正常完成编辑提交草稿。代码/表格取消同样恢复基线，不能残留已写入模型的草稿。
- 元素删除及目录修改同时记录关联；清空/撤销/重做保留画布身份、权限偏好及目录。
- 视图动画由手动输入、新定位、画布切换及卸载取消，并遵守减少动态效果。
- 异步操作绑定任务、画布、元素和版本；取消/撤销/切换后旧结果不能写回。
- 所有新状态验证进入、连续操作、退出、反向恢复、快速重复以及相邻功能。

## 审查范围

覆盖上一轮 34 项发现及 2 项待验证风险。标准语义标题、纯文本没有标题语义、Excel 计算引擎等能力边界不通过猜测改变原数据；保留 Windows 专用能力。不得声称本机已运行 Windows 原生测试。

## 粘贴、排版与性能策略

- 外部 HTML 和 Markdown 中相邻的标题、正文、列表、链接合并为一个富文本元素，文档模型从完整 HTML 重建。图片、独立代码块、表格和独立公式仍保留各自的元素边界。
- 内部复制多个画布元素继续保留独立元素；用户主动“拆分文本”仍有效，并能一次撤销恢复原文。
- 标题语义来自 h1–h6 或 Word 的显式标题/大纲标记，不根据纯文本的视觉大小猜测标题。
- 正文默认 20，标题默认 36/30/26/22/20/18；明确设置的局部字号保留，包含直接设在标题/段落上的字号。段落、标题、列表间距由同一套排版参数供给编辑和显示。
- 编辑器按画布逻辑单位排版，再整体应用相机缩放；缩放不会写回文本字号，也不逐段重写正文。编辑和显示共用宽度、高度、换行和最小高度规则；流程节点保留其节点尺寸。
- 长文输入由编辑 DOM 持有实时草稿，120ms 无新输入后合并模型更新，视口交互中继续延后；保存、提交、导出立即读取草稿。选区/工具栏刷新合并到一帧；取消、切换画布、卸载清理定时器。撤销后迟到任务不得覆盖恢复内容。

## 已落实的相邻修复

- 保存涵盖富文本、代码、公式、表格单元格及备注草稿；保存成功推进恢复基线。撤销删除/清空同时恢复目录关联、画布身份和偏好。
- 代码块保留原生输入与 Tab/Enter 编辑、撤销和中文输入；表格公式使用 KaTeX，Ctrl/Cmd+点击链接仅打开一次。CSV 正确保留换行，Markdown 导出保留支持的语义。
- 图片裁剪先逆旋转/翻转到图片坐标；旋转后的缩放、边界与备注命中修正。异步裁剪检查画布、路径、元素身份、版本与任务，失效结果不改变新模型和历史。
- 转换产生的图片作为 image 元素回插画布；多文件转换仅提供共同支持的操作。文件摘取/搜索增加请求归属，Word 文本可跨分段查找，Unicode 归一化映射回原选区。
- 公式在图片/PDF 导出时离屏生成视觉快照，保留可编辑数据；流程/思维导图节点保留连接 ID 和外框，避免文字重复。
- 后台导出串行使用隐藏画布；取消后的 worker 返回确认才执行下一任务。取消检查贯穿渲染、原生保存对话框和写入前，避免错误画布、取消后落盘及迟到结果污染。
- Word 主进程可只生成 DOCX 字节，画布端通过同一可取消保存适配器选择路径并写入；保留既有 IPC 直接保存接口供旧调用方使用。画布切换和取消能够阻止 Word 对话框返回后的写入。
- 单张导出默认预算 16777216 像素/8192 单边，确认扩大后仍受 67108864 像素/16384 单边硬上限。分块最多 1024 块、单块 2048 单边、编码数据总量 128MiB；原生合成先验证再分配。公式快照单张最多 150 万像素；超预算缓存条目拒绝并释放。

## 验证记录（2026-10-13）

- 新增五个检查脚本：编辑/保存/恢复完整性、富文本粘贴与长文缩放、资源边界、图片几何与异步裁剪、Electron 实际导出。前三个浏览器检查及边界检查接入默认测试套件；桌面导出单独运行。
- 浏览器实测：HTML/Markdown 整段粘贴、内部多元素复制、主动拆分/撤销、显式 48 标题和局部 28 字号、0.5/1/2 缩放下编辑与显示宽高/字号一致。
- 250 段长文连续 60 次缩放，编辑框 60/60 次匹配当前相机、正文子树无缩放引起的属性/结构改写；本机两次 RAF 响应 p95 约 23ms。这是该测试场景的响应时间，不代表所有画布的帧率或性能提升比例。
- 交错输入/缩放后提交、撤销、延迟等待、重做，以及连续五次编辑/取消通过；延迟剪贴板读取不覆盖更新后的草稿。
- 完整回归发现表格单元格进入编辑后，下一帧的光标定位会夺走用户新选区。改为进入时立即定位，延迟帧只更新布局并检查会话版本；新增“立即全选后等待帧”回归，以及保存/取消基线验证。
- 图片 45/90 度与翻转裁剪、旋转缩放、无位移缩放、撤销、备注命中通过。延迟裁剪分别在版本变化、撤销替换元素、切换画布后失效，正常路径仍提交一次历史。
- Electron 在隔离用户目录中实际导出 PDF/PNG，并验证页数/尺寸；文本、表格、流程节点、思维节点公式视觉渲染不修改模型。冷启动取消、原生保存对话框中取消、取消任务 ID 复用和后续任务恢复通过；长文输入后立刻保存包含最新内容。
- Word 原生保存对话框中切换画布后，不生成文件；随后的 Word 导出生成实际 DOCX（ZIP 文件头及大小验证）。结构化和旧版 HTML DOCX 字节生成、两条适配器取消路径通过。
- 文件桌面复验发现搜索跳页会被页码清理逻辑抹掉搜索成功提示。用一次性的搜索导航归属保留目标页结果；手动换页、请求/源文件变化继续清理旧状态。新增等待布局后仍显示结果、手动换页清理、再次搜索与摘取回归，完整文件工作台通过。
- 既有元素交互、37 项剪贴板保真、触控板、文件预览、异步生命周期、HTML 安全、parser/renderer、资源预算和历史等相关回归通过。真实文件工作台测试包括 PDF 摘取/搜索、图片转换/回插、Word/表格/文本 PDF、取消及恢复。
- mac 默认全项目套件通过；Word 保存链补强后额外复验桌面导出、取消边界及 IPC 安全。各分支构建和共享回归在同步后独立检查。构建仍有第三方 html2canvas 既有 duplicate-case 警告。

## 分支与限制

以上属于通用改动，mac 提交后 cherry-pick 到 main、win；各分支独立生成界面包，保留各自的系统适配。不推送远端，不改用户原实验工作树。

macOS 原生 Electron 和浏览器测试在本机执行；Windows 分支运行共享回归和静态/构建检查，本机不能证明 Windows 原生窗口、输入法、文件权限及实际触控设备体验。测试覆盖明确路径，不能据此承诺不存在任何其他 bug。

文件工作台复验曾有一次启动就绪等待超时，后续运行未复现；已补充启动状态诊断。PDF 搜索阶段的另一次超时有明确原因并已修复，不将前者混同为已修复的启动缺陷。
