# 文本输入、排版与结构化内容体验

基线：mac 8095caf、main f85298b、win b4bc605；backup/text-experience-*-20261013 可回退。

## 状态和恢复规则

- 进入编辑：原文进入 DOM 草稿，记录保存/取消基线；候选窗由操作系统管理。
- 进入输入法组合期：原生输入持有 DOM 和选区，不执行 Markdown 快捷转换、换行、取消或重写正文；相机仅更新框架变换。
- 组合结束：读取最终草稿，恢复格式状态/尺寸更新；保存和导出始终读取实时草稿。
- 真正离开编辑、取消、切换画布、卸载：清理组合标记、排队更新和旧选区；迟到事件不能写回另一会话。
- 表格/代码：输入和视觉层分离，语言/高亮/选区状态在退出和再次进入后恢复。
- 排版：标题、正文和格式共用逻辑尺寸；用户显式设置优先。缩放不改变持久化字体。
- Markdown：所有入口使用同一解析器；公式、脚注、任务、下划线是明确扩展。HTML 仅允许受控行内标记，禁止任意执行内容。

## 已完成的修改

- Mac 使用 floating 置顶层级；blur 不再强制抬升窗口。Windows 维持原置顶行为。
- 富文本、表格单元格、代码、公式、备注与全局快捷键共同保护 IME 组合期；组合结束后恢复草稿同步。
- 编辑、显示、隐藏测量共用排版：正文 20px/400，H1–H6 为 40/34/29/25/23/21；用户明确指定的字号优先。
- Markdown 三个入口统一使用 markdown-it，保留公式、任务、脚注、下划线；禁止任意 HTML，保留代码缩进/空行/语言。
- 工具栏保留常用格式，更多格式收纳次要操作；嵌套色板、取消和重新进入时正确恢复。
- 表格的内边距、表头和对齐，以及代码块等宽字体、边框与测量同步调整。
