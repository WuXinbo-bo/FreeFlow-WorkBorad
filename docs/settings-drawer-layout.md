# 设置抽屉：布局与状态验收

本次为跨平台通用改动。只有画布插件采用独立卡片；画布设置采用目录表单和编辑开关，GitHub 同步采用连接信息、同步位置和远程画布列表。

## 布局

- 保持右侧半屏抽屉，根据抽屉自身宽度重排，不再仅依赖整个窗口的断点。
- 狭窄抽屉使用分类选择器，为实际设置留出宽度；页头与页脚固定在各自布局位置，内容独立滚动。
- 目录输入、操作按钮分行；长路径和仓库名称换行；反馈与按钮在短窗口中自然撑开。
- 插件卡片包含身份、状态、主要操作和可展开的更多操作，可供后续插件复用展示结构。

## GitHub 操作语义

- 进入页面只读取当前工作区目录，不保存画布、不执行同步。
- 批量拉取使用实际工作区上下文，完成后通知文件列表刷新；单个画布首次拉取仍通过保存对话框选择位置。
- “上传当前文件夹”仅上传，不承诺同时拉取。批量处理汇总失败、冲突及待处理删除，存在问题时显示警告。
- 当前目录的检查计划优先于历史同步记录；目标路径存在不等于文件已下载，只有 `localHash` 可确认计划中的本机副本。
- 未检查的历史记录标明“上次检查 / 上次保存位置”。没有本机路径时不调用会回退到默认画布的状态查询。
- 保留已绑定仓库的分支，支持 ISO 格式的远端更新时间。

## 恢复路径

- 同页异步刷新保留滚动位置、展开和收起状态、键盘焦点及当前输入选择。
- 目录草稿跨分类和关闭后重开保留，仍通过保存或放弃显式处理。
- 插件关闭、卸载需确认；取消后回到原操作，安装和启用生命周期沿用已有逻辑。
- 目录读取通过序号、页面和打开状态校验；快速切页、关闭后丢弃过期回填。
- 更换仓库、重新载入或断开连接清理旧列表、检查计划与冲突信息。

## 验证入口与边界

- `node scripts/check-settings-drawer-layout.js`：真实前端模块与样式，覆盖多尺寸、五主题、长路径、远程列表、批量操作反馈、展开恢复和临时输入。
- `node scripts/check-settings-github-browser.js`：令牌与设备授权切换、重试、绑定和断开。
- `node scripts/check-assistant-plugin-ui.js` / `check-assistant-plugin-desktop.js`：插件操作以及隔离数据目录下的真实 Electron 生命周期。
- `node scripts/check-github-sync-multidevice.js`：本地隔离的双设备同步与下载恢复测试。
- `node scripts/run-test-suite.js`：项目共享回归。

GitHub 页面测试使用隔离的模拟服务，不访问用户真实仓库；Electron 测试使用临时用户目录，不清除真实配置。macOS 上的共享检查不能代替 Windows 原生桌面验收。
