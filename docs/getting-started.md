# 开始使用 FreeFlow

[返回首页](../README.md) · [GitHub 同步](github-sync.md) · [AI 助手插件](assistant-plugin.md)

## 安装与第一次使用

1. 从 [Releases](https://github.com/WuXinbo-bo/FreeFlow-WorkBorad/releases) 查看已公开的系统与架构。目前公开应用版本 v2.0.2 提供 Windows 附件；Mac 仅有本地测试包，尚无公开下载，可按下文从源码运行。
2. Windows 运行安装包；免安装版直接运行。Mac 将解压后的 `FreeFlow.app` 放入“应用程序”，再启动。
3. 打开或创建本地工作区，创建画布。无需 GitHub 或 AI 账号即可开始使用。
4. 将一段带格式文本、图片或本地文件拖入画布，选中后使用相关工具，双击可编辑支持的元素。
5. 将画布保存为 `.freeflow`，按需启用自动保存。重要内容同时备份相关附件。

自行构建或取得的 Mac 本地测试包目前未公证，系统可能阻止首次打开。先核对来源，再参考 [Apple 官方指南](https://support.apple.com/102445)；不需要关闭 Gatekeeper。已发布版本与源码分支可能不同，以下载页附件为准。

## 整理与编辑

- 将文本、图片、文件卡片、表格、代码、公式、图形和思维导图放在同一画布。
- 拖动内容或视口，缩放查看整体，再进入元素编辑。Mac 支持触控板双指移动及捏合缩放。
- 工作区管理画布文件，当前画布目录帮助定位内容；搜索可查找工作区内的画布及已支持的内容。
- 使用选中内容的操作菜单进行复制、排列、分组、锁定、编辑与导出。可用动作由内容类型决定。
- 删除的画布可从工作区回收站恢复，历史版本可从画布操作菜单查看。本地恢复记录不会作为历史目录上传 GitHub。

完全穿透的默认快捷键为 Mac `⌘⇧X`、Windows `Ctrl+Shift+X`，可在“系统设置 → 工作台习惯”中重新录制。完全穿透后按相同组合恢复交互；其他软件占用组合键时需要更换。

## 文件预览与转换

文件卡片通过操作菜单打开预览，可以放大阅读、搜索、摘取支持的内容、刷新源文件、重新关联或用系统应用打开。阅读预览不会把原文件变成完整 Office 编辑器。

| 来源 | 画布内预览 | 文件转换 |
| --- | --- | --- |
| PDF | 页面、文字层、文字查找与选取；扫描件无原生文字层时不能直接搜索 | 指定页面转图片，页面／区域图片添加到画布 |
| DOCX | 文档阅读，版式以实际预览为准 | 转 PDF 需要本机 LibreOffice |
| CSV、TSV、XLSX | 表格与工作表 | CSV／TSV／XLSX 互转；XLSX 转 PDF 需要 LibreOffice |
| TXT、Markdown | 文本阅读 | 转 Word／PDF；Markdown 转 Word 保留基础标题与正文，不承诺全部扩展语法 |
| JSON、YAML、XML、HTML、CSS、JS、TS、Python、Shell、Log 等 | 文本／代码阅读 | 以工具中实际提供的目标格式为准 |
| PNG、JPEG、WebP | 图片 | 格式互转、调整尺寸、合并 PDF |
| PPTX | 当前没有幻灯片内嵌预览 | 转 PDF 需要本机 LibreOffice |
| 其他文件 | 以文件卡保存关联，可用系统应用打开 | 不提供通用任意格式转换 |

转换前选择参数与输出目录。完成后可打开文件夹，或将生成结果批量添加到画布；画布插入支持撤销，撤销不会删除已经生成的磁盘文件。转换失败或取消时不把临时产物显示为成功结果。

CSV 是值格式，不保留工作簿的样式、图片和公式。Office 转 PDF 依赖本机 LibreOffice，缺少引擎会明确提示；字体和应用差异可能影响版式。OCR、扫描 PDF 转可编辑 Word、完整 Office 往返编辑不属于当前能力。

预览、图片像素、页数、转换任务和缓存均有上限，大文件可能无法内嵌处理。请以应用提示为准，必要时使用系统应用打开原文件。开发验证记录及精确预算见 [文件工作台说明](FILE_WORKSTATION_20261011.md)。

## 输出成果

- 选中需要的内容，再选择相应导出方式。
- Word 导出预览允许调整阅读顺序；图片、公式等按支持的模型输出。导出界面会列出无法转换的项目。
- 画布图片／PDF 导出与文件转换属于不同操作；前者输出画布排布，后者加工源文件。
- 对外发送前检查导出内容、附件完整性和阅读顺序。不要仅发送带有本机路径的画布就假定对方拥有全部资源。

## 数据与备份

| 默认内容 | Windows | macOS |
| --- | --- | --- |
| 画布目录 | `%USERPROFILE%\FreeFlow\CanvasBoards` | `~/Library/Application Support/FreeFlow/CanvasBoards` |
| 应用数据 | `%USERPROFILE%\FreeFlow\AppData` | `~/Library/Application Support/FreeFlow/AppData` |

设置中选择的目录或启动环境变量会改变这些路径。外部文件卡仍可能引用原位置；移动或删除源文件后，通过“重新关联”修复关联。

备份时关闭应用，保留画布、应用数据和实际使用的附件。应用数据可能包含账号凭据及会话，备份应放在自己控制的位置，不要提交到源码仓库。回收站、历史恢复与 GitHub 同步各有范围，均不意味着任意外部附件自动得到备份。

## 需要同步或 AI 时

- 在“系统设置 → GitHub 同步”连接自己的私有仓库。另一台设备选择本地工作区后连接同一仓库，再检查与拉取。详见 [同步指南](github-sync.md)。
- AI 镜像由主程序提供，来源和交互能力因系统而异。
- AI 助手在“系统设置 → 画布插件”按需安装，签名校验和自检成功后下次启动启用。停用或卸载助手不会删除画布，保留的助手数据按插件说明管理。

## 从源码启动

安装 Node.js 24 LTS 或更高版本，进入对应分支的项目根目录：

```sh
npm ci
npm run prepare:desktop-build
npm run start:desktop
```

依赖和资源已准备好后，Mac 可双击 `Start-FreeFlow.command`，Windows 可双击 `start-desktop.cmd`。脚本不会自动拉取 Git 或安装依赖；源码变化后按需要重新构建。

`npm start` 只启动开发网页服务。默认端口为 `53127`，被占用时以终端打印的地址为准。需要固定其他端口时使用 `FREEFLOW_PORT`；设为 `0` 由系统分配。

## 遇到问题

先记下版本、系统、复现步骤与完整错误；检查应用内更新与 [已有 Issues](https://github.com/WuXinbo-bo/FreeFlow-WorkBorad/issues)。提供最小脱敏样本，不要上传访问令牌、模型密钥或私人工作区。文件丢失时优先保留当前目录与恢复记录，避免连续覆盖保存。
