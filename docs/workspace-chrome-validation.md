# 工作区控件与小地图验证（2026-10-10）

本轮为跨平台通用前端改动。mac、win、main 使用同一源码提交；各分支独立重建已跟踪的画布包，保留各自平台实现。

## 行为与恢复规则

- 左上面板控制键为 28px，窄 AI 面板为 24px；悬停与按下不移动按钮位置。
- 画布工具栏上移，顶部拖动区保留 12px，避免挡住工具按钮；边缘拖动、取消、失焦后恢复。
- AI 助手、镜像、切换锁定、映射入口保持同一行；隐藏面板保留紧凑状态，恢复立即重算。全局设置按钮的占位参与布局。
- 目录展开状态为本机偏好。切换只更新界面，不修改画布内容、脏状态或触发同步。无本机偏好时读取旧画布的默认状态，兼容旧文件。
- 小地图默认收起，手动选择持久化到本机。目录切换不会打开小地图。
- 小地图展开且空间足够时绘制；收起、遮挡或页面隐藏时停止绘制。编辑期间失效的快照在展开、空间恢复或页面可见时补绘。
- 临时遮挡只改变可见性，不覆盖用户的展开偏好。收起外壳不拦截底层点击，展开按钮仍可操作。
- 桌面工作区与独立画布使用各自最近的画布容器定位小地图，避开缩放栏与目录。
- 结构化画布替换入口显式失效场景索引与显示快照，防止相同元素 ID 保留旧锁定状态或旧小地图；该刷新不保存、不新增脏状态。
- AI 历史阅读时保持滚动位置，返回底部后恢复流式跟随。后台刷新立即恢复滚动位置，避免 CSS 平滑滚动中的中间位置误关闭跟随；手动返回底部仍保留平滑滚动。
