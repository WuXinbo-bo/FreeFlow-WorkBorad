# 签名与安全边界

安装包使用 `.ffplugin` 格式，manifest 由 Ed25519 签名，宿主内置受信公钥。每个文件均校验大小与 SHA-256，下载还与目录记录的包大小、哈希比对。离线导入执行相同校验。

`trust/assistant-ed25519.pub` 是方便维护者检查目录的公开验证密钥。客户端不会从目录接受新的信任根；修改它不可能让旧客户端信任另一个密钥。

HTTPS 目录可以更新，但不能绕过宿主对包签名、平台、应用版本、API 和文件清单的检查。发布账号应保护分支和签名私钥，限制维护者权限；没有受信签名的第三方包不可安装。

插件进程隔离用于回收资源与隔离崩溃，不是操作系统安全沙箱。当前只发布官方插件。未来第三方生态需要单独设计权限、受限 API、审核和信任机制。

插件安装不执行 `npm install` 或第三方安装脚本，不修改签名后的 `.app` 或 Windows 安装目录。用户同步 Token、模型密钥及签名私钥不能进入目录、发布附件或日志。
