# 兼容与生命周期

每个目录记录包含插件 ID、版本、宿主 API 版本、最低应用版本、可选最高应用版本、平台和架构、固定下载 URL、包大小、SHA-256、签名清单及签名。

主程序先筛选与本机、应用和宿主 API 兼容的记录，再选择最高版本。没有兼容版本时明确提示，不下载其他系统的包。旧的单条目录格式仍可读取。

`darwin` 对应 macOS，`win32` 对应 Windows，`any` 仅用于不含对应平台或架构限制的插件包。新增平台前必须完成实际适配及原生测试。

| 阶段 | 行为与恢复 |
| --- | --- |
| 未安装 | 画布和镜像正常使用，不加载助手，不探测 CLI |
| 下载、校验、自检 | 可取消；失败保留旧版本，清理临时文件 |
| 安装完成 | 不在本次启动中强行启用；提示下次启动 |
| 启用 | 验证文件后允许加载，助手后台实际使用时才启动 |
| 停用 | 阻止新请求，停止后台；保留程序与用户数据 |
| 更新 | 安装新目录；本次旧版本继续，下次启动切换 |
| 卸载 | 停止后台并删除程序；保留会话、配置与凭据 |
| 重装 | 再次校验、自检、重启启用，恢复兼容的用户数据 |

升级不能强制开启用户已经停用的插件。卸载失败需要保留诊断与重试入口；损坏包不能启用。镜像与普通设置不依赖助手安装状态。
