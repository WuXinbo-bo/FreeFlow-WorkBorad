# 数学公式与链接兼容修复

## 用户行为

- 行内公式可以输入 `$x^2$`；独立公式可以输入 `$$` 包围的多行 LaTeX。
- 兼容 `\(...\)`、`\[...\]`，正文中的 `$$...$$` 保留在原段落中。
- 编辑时显示美元分隔符，持久化节点保存 LaTeX 源；重新编辑、复制及 Markdown 导出使用相同规则。
- 未闭合输入保留原文；代码和链接中的美元不自动转公式。普通金额如 `Price $5 and $10` 保留为文本。
- 保存富文本中的块公式不会再自动拆成多个画布元素；显式“拆分文本”命令保持原行为。
- 富文本和表格显示态可单击打开链接；编辑态单击用于编辑，macOS 使用 Cmd+点击、Windows 使用 Ctrl+点击打开。
- 链接拖选超过 5px 后不导航，即使指针回到起点。画布内部链接继续定位目标元素。
- 外部链接通过 Electron IPC 等待系统调用结果，失败时显示失败提示。仅允许 HTTP、HTTPS、mailto、tel；本地文件继续走已有文件访问授权接口。

## 状态与恢复

| 场景 | 进入与连续操作 | 退出与恢复 |
| --- | --- | --- |
| 富文本公式编辑 | 编辑器保留美元源；输入法组合期间不改活 DOM；序列化只处理副本 | 提交生成规范节点；再次编辑恢复源；Esc 回滚；撤销/重做恢复文档 |
| 多行公式 | 只合并完整相邻段落中的围栏 | 遇到图片、代码、链接、列表、表格或中间正文时停止合并，保留原内容 |
| 链接手势 | pointerdown 记录起点，持续记录最大移动范围 | click 消费手势；取消、失焦及画布指针清理时重置 |
| 异步链接打开 | 经 preload、安全 IPC、主进程 URL 校验到 shell | 打开失败显示错误；返回前切换画布时不把状态写入另一画布 |

原有文档不做批量迁移；读取/编辑时兼容已有结构化公式节点和带分隔符的公式源。

## 平台与测试边界

这是通用改动，源代码通过同一提交同步到 `mac`、`main`、`win`，桌面平台层原有差异保留。构建文件在各分支分别生成。

桌面链接测试走真实 renderer → preload → 安全 IPC → main 链路。最后的 `shell.openExternal` / Finder 调用被记录器替代，避免测试弹出外部应用；因此这不等同于已验证浏览器实际访问网页。Windows 原生窗口、默认浏览器与系统关联需在 Windows 机器验收，Mac 上仅运行共享测试与 Windows 打包/代码契约检查。

本轮仅本地提交，不推送远程。默认旧工作树的既有修改、用户画布与正在运行的原应用不参与测试。
