# GitHub 同步与可选助手组件：本轮补强

## 范围

本轮处理同步的数据保护、任务结果、设置布局与组件生命周期。全部为跨平台通用改动，维护 `mac`、`main`、`win` 的等价实现，保留各平台的窗口、路径和构建配置。不推送远程，不发布 Release，不操作用户现用画布、凭据或插件目录。

## GitHub 设置

同一设置页分为三个内部页签：

- **工作区同步**：当前文件夹、待上传/待拉取/待处理数量、检查和批量操作；已同步内容收起。
- **远程画布**：查看仓库画布，默认拉取到当前工作区；其他保存位置作为次级操作。
- **连接与规则**：账号、私有仓库、两种互斥授权方式、附件说明和断开连接。

常驻摘要展示当前连接与仓库，避免所有配置同时展开。长路径、窄屏、主题与冲突详情都纳入浏览器布局回归。插件继续使用可扩展的卡片；GitHub 同步和画布设置不改成插件卡片。

## 同步判断与文件保护

| 场景 | 行为 |
| --- | --- |
| 双方内容相同 | 已同步，不因仓库中无关提交制造画布冲突 |
| 本地或远端单方修改 | 分别待上传、待拉取 |
| 无共同基线且内容不同 | 双方有修改，必须明确选择或人工处理，批量上传不覆盖 |
| 同一 ID 出现于多个本地文件 | 报重复身份，保留所有副本，停止该画布自动同步 |
| 只改名、移动子目录 | 根据保存的相对路径区分本机/远端重命名；冲突停止覆盖 |
| 本机文件缺失 | 可从远端拉回，不把“找不到文件”等同于确认删除 |
| 远端删除标记 | 普通上传、拉取均不自动删除或复活 |
| 同名不同 ID、路径不兼容、符号链接 | 阻止覆盖或越界访问，并报告原因 |

工作区扫描递归读取画布，跳过隐藏目录、资源目录、依赖和符号链接；无关 JSON 不写入画布 ID。设置层限制扫描深度与条目数，避免误选大目录无限遍历。远端保存路径采用跨平台校验，不使用远端自由名称直接拼接本地路径。

合并基于共同祖先，保留元素顺序与新增元素位置；双方顺序冲突明确报告。合并引用的远端附件先读取、核对长度与 SHA-256，再写入本地资源；不把远端图片悄悄变成占位符。覆盖、合并与确认删除沿用历史/回收站恢复能力。

后端另提供明确删除接口：`deleteRemoteBoard` 需要确认及刚检查的远端 SHA，只写删除标记，保留远端文件；`applyRemoteDeletion` 再校验本地 ID、内容 hash 和确认版本，放入本地回收站。普通批量同步不调用删除接口。

## 操作任务与恢复

操作入口统一进入可查询任务记录。Electron 先生成操作 ID，只提交一次，随后按 ID 查询结果；旧 HTTP 路径也经过同一任务守卫。

```text
queued → running → completed / failed
             ↓ 执行超过 30 秒或提交结果不明
         confirming
             ↓ 远端确认后，但本机后续步骤未核对
         interrupted → 检查当前文件夹成功 → 允许后续写入
```

- 同一 ID、同一参数重复请求返回原任务；不同参数不可复用 ID。
- 一次只允许一个同步任务。连接中断时保留待确认状态和画布文件操作保护，不重复上传。
- GitHub 更新分支响应丢失且 HEAD 也不可查询时，保存候选提交 SHA 和仓库信息；恢复连接后查询 HEAD/提交关系，确认是否进入当前分支，不盲目重发。
- 远端确认发布，不代表未执行的本地保存、账本写入已完成；先核对工作区，再继续。
- 应用退出时的普通未完成任务变为中断；已记录的未知提交继续确认。缺失任务记录也要求先检查差异，而非永久轮询不存在的任务。
- 结果已确定后的账本、任务记录或列表刷新失败单独提示，不撤销已确认的提交/保存结果。
- 文件变更事件在本机写入完成后立即发出；刷新远程列表不再延长“上传中”或阻止工作区更新。

任务记录保存于用户数据目录，原子写入，最多保留近期 16 项；不记录令牌、画布正文与附件字节。它用于恢复操作结果，不是画布备份格式。

## 多设备检查

宿主在启动、窗口激活及可见状态下适度检查远端分支引用。正常间隔至少一分钟，未连接时延长；隐藏窗口暂停，失败退避并遵守服务端等待时间。状态刷新不能绕过退避。

检查使用 ETag，仅查询分支引用，不扫描或下载画布；启动后的首次查询也对照持久账本，避免漏掉应用关闭期间另一台设备的修改。自己已确认上传的 SHA 不重复提示。发现变化后提示检查/拉取，不在后台覆盖正在编辑的画布。

这属于个人多设备同步，不宣称实现多人实时共同编辑。

## 助手组件卡片与恢复

| 状态 | 主要交互 |
| --- | --- |
| 未安装 | 有真实下载源时安装；未发布时明确说明并允许导入签名包 |
| 下载/校验/自检中 | 展示当前阶段与进度，允许取消 |
| 安装成功 | 下次启动启用；当前运行能力不伪装成已切换 |
| 已启用或停用 | 显示实际状态，允许切换；更新保留停用意愿 |
| 当前文件损坏 | 显示当前验证失败，允许修复或卸载 |
| 停用/卸载失败 | 保留真实状态、重试入口与持久清理意愿 |
| 卸载完成 | 回到安装界面，保留会话和设置 |

UI 在修改操作中不让迟到的 GET 覆盖新状态；失败后重新读取真实状态。安装发布成功后的可选旧目录清理失败不再把安装成功变成失败。完整生命周期同时验证快速重复、失败、退出和下一次启动的反向路径。

## 验证与限制

新增确定性回归覆盖多设备基线、重复身份、重命名、附件合并、元素顺序、路径/符号链接、明确删除及恢复、提交不确定结果、任务丢包、HTTP 兼容入口、轻量检查与退避。设置使用真实浏览器检查布局和状态生命周期；插件使用实际签名包、HTTP 下载、独立自检和隔离 Electron profile 验证。

测试使用临时目录、测试令牌和可控 GitHub 协议服务，不使用历史聊天里的令牌，不创建真实仓库。两套设备目录及独立账本用于模拟 Windows/Mac 的共享数据流程；Mac 原生验证不能替代 Windows 原生安装测试。

本轮签名包已能本地下载安装。公网默认 catalog 尚未发布；构建注入真实 HTTPS 地址与发布门禁已实现，正式发布后仍需用目标地址完整验证。不能把本地 HTTP 测试说成公网已可下载。详细发布步骤见 `docs/assistant-plugin.md`。
